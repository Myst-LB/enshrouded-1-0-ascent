# Enshrouded 1.0 · The Ascent

The Enshrouded 1.0 patch notes reimagined as a scroll-driven web experience: a climb out of the Shroud, from Cinder's Cradle to the summit.

**Live site:** https://myst-lb.github.io/enshrouded-1-0-ascent/

## What's inside
- WebGL Shroud fog and cursor-reactive embers in the hero, with a live Steam launch countdown (Canada / Algeria)
- Atlas of every biome, the new spell grimoire, and the 37 new enemies
- Sparkworks: a playable logic circuit plus animated breakdowns of Keen's five showcase dungeon rooms
- Brick renderer before/after slider
- "Choose your path" with Keen's work-in-progress combat clips per playstyle
- A searchable, filterable codex of the 1.0 changelog

Single self-contained `index.html`, no build step.
